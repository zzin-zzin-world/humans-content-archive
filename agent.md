## Purpose

`HumanArchive` records image (or content) hashes and lightweight metadata on-chain so anyone can verify a piece of media was registered as human-generated content. It stores both the original payload hash and its certified wrapper hash, ties them to the submitting account and timestamp, and supports lookup for either form. Access to registration is owner-gated; verification is open to all.

Refer to `skills.md` for World Mini Apps API details when wiring proofs or off-chain integrations.
